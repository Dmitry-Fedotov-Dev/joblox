# Безопасность

Нашли уязвимость: не публикуйте её в issues. Напишите через приватное сообщение о уязвимости на GitHub
(вкладка Security → Report a vulnerability). Ответим и выпустим исправление, затем опишем проблему публично.

Как защищены реквизиты и формы: [docs/ANTIFRAUD.md](docs/ANTIFRAUD.md).
