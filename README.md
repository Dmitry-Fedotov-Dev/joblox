# Joblox

[![CI](https://github.com/Dmitry-Fedotov-Dev/joblox/actions/workflows/ci.yml/badge.svg)](https://github.com/Dmitry-Fedotov-Dev/joblox/actions/workflows/ci.yml)
[![License: AGPL-3.0](https://img.shields.io/badge/license-AGPL--3.0-blue.svg)](LICENSE)

Открытый конструктор сервисов оказания услуг: своя служба такси, курьерская доставка, грузоперевозки,
пекарня с самовывозом, интернет-магазин или агентская оплата услуг. Это программная обвязка над
операционным процессом: витрина и форма заказа для клиента, статусы заказа, бот для операторов,
приём оплаты на ваши реквизиты с защитой от мошенников и дашборд нагрузки.

Порядок работы бизнеса задаётся одним YAML-файлом (профилем): что продаётся, какие поля заполняет клиент,
как считается цена, через какие статусы проходит заказ и кто может его двигать. Код менять не нужно.

Запускается прямо на телефоне с Android или на компьютере: одна команда, и через минуту у вас сайт с публичной
ссылкой и кабинет в браузере. Сервер, домен и деньги на старт не нужны. Для серьёзной нагрузки тот же бинарник
работает на VPS за 5 долларов в месяц.

Все установки, которые этого хотят, видны на бирже https://joblox.openline.one: клиент открывает её и сразу
заказывает такси, доставку или выпечку у исполнителей рядом.

## Что внутри

| | |
|---|---|
| Витрина и заказ | Каталог с корзиной или заявка с ценой по запросу, поля формы из профиля, проверка ввода |
| Статусы | Граф статусов из профиля: кто (клиент, оператор, система) и при каких условиях (оплачен, одобрен, цена названа, email подтверждён) переводит заказ |
| Оплата | Перевод на ваши реквизиты или оплата при получении. Реквизиты видны только на странице проверенного заказа, с номером заказа в назначении платежа |
| Антифрод | Код на email, лимиты по адресу и почте, ловушка для ботов, проверка скорости заполнения, одноразовые ящики, чёрный список, ручная проверка крупных и новых заказов |
| Бот операторов | Telegram: карточка каждого заказа с кнопками разрешённых сейчас переходов, отметка оплаты, цена по запросу, чёрный список, пауза приёма |
| Дашборд | Встроенный: онлайн, запросы в секунду, время ответа, процессор и память сервера, заказы за сутки. Плюс метрики Prometheus и готовый дашборд Grafana |
| Хранилище | SQLite в одном файле, журнал событий заказа без возможности правки задним числом |
| Joblox Network | По желанию владельца: анонимный счётчик установок, людей онлайн и заказов, открытое API |

Готовые профили в [`profiles/`](profiles):

| Профиль | Бизнес | Цена | Особенности |
|---|---|---|---|
| [`bakery.yaml`](profiles/bakery.yaml) | Пекарня на вынос | Каталог | Время самовывоза, оплата заранее или на месте |
| [`shop.yaml`](profiles/shop.yaml) | Интернет-магазин | Каталог и доставка | Доставка бесплатно от суммы, оплата до сборки |
| [`delivery.yaml`](profiles/delivery.yaml) | Курьерская служба | Тариф и рубли за килограмм | Откуда, куда, телефон получателя |
| [`taxi.yaml`](profiles/taxi.yaml) | Такси по предзаказу | Посадка и рубли за километр | Маршрут, время подачи, пассажиры |
| [`freight.yaml`](profiles/freight.yaml) | Грузоперевозки | По запросу | Диспетчер называет цену, клиент подтверждает |
| [`agent-pay.yaml`](profiles/agent-pay.yaml) | Агентская оплата услуг | По запросу | Ручная проверка каждой заявки, только безнал |

## Запуск за 5 минут: на телефоне или компьютере

**Android.** Поставьте [Termux](https://f-droid.org/packages/com.termux/) из F-Droid, откройте и вставьте:

```bash
curl -fsSL https://raw.githubusercontent.com/Dmitry-Fedotov-Dev/joblox/main/install.sh | sh
```

**Windows.** В PowerShell:

```powershell
irm https://raw.githubusercontent.com/Dmitry-Fedotov-Dev/joblox/main/install.ps1 | iex
```

Или скачайте `joblox-windows-amd64.exe` из [последнего релиза](https://github.com/Dmitry-Fedotov-Dev/joblox/releases/latest)
и откройте двойным щелчком. **Mac и Linux:** та же команда, что для Android.

Что происходит дальше (`joblox up`):

1. Программа скачивает cloudflared (проверяя контрольную сумму) и получает временную публичную ссылку
   `https://….trycloudflare.com`. Другого выбора при запуске нет, всё работает сразу.
2. В браузере открывается мастер-ссылка: вход владельца. Её же программа печатает в окне.
3. Владелец выбирает роль (такси, курьер, пекарня, перевозки, магазин), вписывает название, телефон, место и
   куда переводить деньги, принимает соглашение и отмечает «Показать на бирже».
4. Сайт перезапускается под этот бизнес. В кабинете большая кнопка «Перейти в ваше приложение» и QR-код
   ссылки для клиентов. Заказы видны с кнопками: одобрить, назвать цену, оплата получена, следующий статус.
5. Пока заказ открыт, у клиента и исполнителя есть кнопка «Позвонить»: голосовой звонок по ссылке через
   [Контакт](https://openline.one/), без номеров телефонов. Заказ закрыт, кнопка пропала.

Все файлы лежат в папке `joblox-data` рядом с программой: профиль, база, ключи, `joblox.env` с настройками.
В кабинете есть инструкции: постоянный адрес на своём домене через Cloudflare Tunnel, почта, Telegram-бот,
цены и каталог, работа на телефоне. Оплата идёт напрямую исполнителю по его реквизитам: у переводов по номеру
телефона нет открытого API, поэтому поступление денег отмечает владелец.

## Для разработчиков

Нужен Go 1.26 или новее.

```bash
go build -o bin/joblox ./cmd/joblox
JOBLOX_ENV=dev JOBLOX_PROFILE=profiles/bakery.yaml JOBLOX_REQUISITES=deploy/requisites.example.yaml ./bin/joblox serve
```

- Витрина: http://localhost:8080
- Письма с кодами (в режиме разработки они не отправляются): http://localhost:8080/dev/outbox
- Дашборд: http://127.0.0.1:9180/admin

Проверить свой профиль и посмотреть граф статусов:

```bash
./bin/joblox check profiles/taxi.yaml
```

## На сервер

Коротко: VPS с Docker, домен, направленный на сервер, файл `.env` и файл реквизитов.

```bash
cp deploy/.env.example deploy/.env                     # домен, секрет, почта, бот
cp deploy/requisites.example.yaml deploy/requisites.yaml && chmod 600 deploy/requisites.yaml
docker compose -f deploy/docker-compose.yml up -d --build
```

Caddy сам получит сертификат HTTPS. Подробно, включая установку без Docker: [docs/DEPLOY.md](docs/DEPLOY.md).
