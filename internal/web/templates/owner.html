Инструкции

Файлы программы лежат в папке {{.DataDir}}. Настройки пишутся в файл joblox.env в этой папке, после правки перезапустите программу.

Свой домен вместо временной ссылки
  1. Купите домен у любого регистратора (около 10 долларов в год) и добавьте его в бесплатный аккаунт Cloudflare.
  2. В Cloudflare откройте Zero Trust, затем Networks, Tunnels, «Create a tunnel», тип Cloudflared. Назовите его, например, joblox.
  3. Скопируйте токен из команды установки (длинная строка после --token). Саму команду запускать не нужно.
  4. В Public Hostname укажите адрес, например taxi.example.com, тип HTTP, адрес localhost:8080.
  5. Допишите в joblox.env:
    CLOUDFLARE_TUNNEL_TOKEN=токен
JOBLOX_BASE_URL=https://taxi.example.com
  6. Перезапустите программу. Ссылка станет постоянной, биржа покажет новый адрес сама.

Есть свой сервер (VPS)? Тогда программу лучше запустить на нём: инструкция.

Оплата

Клиент переводит деньги вам напрямую по реквизитам, которые вы указали при запуске: номер телефона в банке или кошельке, карта. На странице заказа он видит их вместе с номером заказа для назначения платежа, только после вашей проверки.

Пришли деньги: нажмите «Оплата получена» у заказа. Joblox деньги не принимает и не хранит. Автоматически узнать о переводе программа не может: у переводов по номеру телефона нет открытого API для этого.

Реквизиты лежат в файле requisites.yaml. Поменять: исправьте файл или удалите settings.json и пройдите запуск заново.

Почта

С почтой клиенты получают письма о статусе заказа, а коды подтверждения email защищают от фальшивых заказов. Подойдёт любой SMTP: Gmail с паролем приложения, Яндекс, Mail.ru, Brevo. Допишите в joblox.env:

SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=you@gmail.com
SMTP_PASSWORD=пароль приложения
SMTP_FROM=Такси Азамат <you@gmail.com>
Заказы в Telegram

Бот присылает каждый новый заказ с кнопками. Создайте бота у @BotFather и допишите в joblox.env:

TELEGRAM_TOKEN=токен от BotFather
JOBLOX_OPERATORS=ваш Telegram id

Свой id узнаете, написав боту после перезапуска: он ответит числом.

Цены, каталог, поля заказа

Всё описано в файле profile.yaml: товары и тарифы, поля формы, статусы заказа. Откройте его в любом редакторе, поправьте и перезапустите программу. Описание профиля.

Работа на телефоне
  • Сайт работает, пока включены телефон, интернет и Termux. Держите телефон на зарядке.
  • Termux не должен засыпать: в его уведомлении нажмите «Acquire wakelock», а в настройках Android отключите для Termux экономию батареи.
  • Запустить снова: откройте Termux и наберите joblox up.
