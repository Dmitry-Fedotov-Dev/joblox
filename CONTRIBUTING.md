# Участие

Спасибо за желание помочь. Как устроен проект: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

- Перед пулл-реквестом: `gofmt -l .` пусто, `go vet ./...` чисто, `go test -race -count=2 ./...` зелёный.
- Новое поведение покрывайте тестом рядом с кодом. Ошибку сначала воспроизведите тестом.
- Новый тип бизнеса добавляйте профилем в `profiles/`, а не кодом, если хватает возможностей профиля.
- Дашборд Grafana правится в `monitoring/grafana/gen_dashboard.py`, JSON пересобирается генератором.
- Зависимости добавляйте только при настоящей необходимости: каждая увеличивает поверхность атаки.
- Тексты для клиентов пишите простым деловым языком, без рекламных оборотов.
