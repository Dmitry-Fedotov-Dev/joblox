# Joblox Network

Публичный счётчик на https://joblox.openline.one: сколько установок Joblox работает сейчас, сколько людей на их сайтах и сколько у них заказов
за сутки. Для интереса, без рекламы и без каталога магазинов.

## Как подключить свою установку

Участие выключено по умолчанию. Чтобы включить, задайте адрес сети:

```bash
JOBLOX_NETWORK_URL=https://joblox.openline.one
```

Раз в 5 минут установка отправит одно сообщение:

```json
{"id": "a3f1…(32 символа)", "kind": "bakery", "version": "1.0.0", "online": 7, "orders_today": 3}
```

- `id` случайный, создаётся при первом включении и хранится в базе установки. По нему нельзя узнать бизнес.
- `kind` берётся из `business.kind` профиля. Всё, кроме латиницы, цифр, `_` и `-`, сеть превращает в `other`.
- `online` и `orders_today` берутся из тех же счётчиков, что на встроенном дашборде.

Названия, адреса, товары, цены, клиенты, платежи в сеть не отправляются. Чтобы выйти из сети, уберите
переменную: через 15 минут установка пропадёт из счётчика, через 7 дней запись удалится.

## Открытое API

| Запрос | Ответ |
|---|---|
| `GET /api/v1/stats` | `{"installations", "online", "orders_today", "kinds", "updated_at"}`, с CORS для любого сайта |
| `POST /api/v1/beat` | `204`, если принято; `400` при неверных полях (лишние поля тоже ошибка); `429` чаще раза в минуту |
| `GET /` | Публичная страница со счётчиками, без скриптов |

Установка считается работающей 15 минут после последнего сообщения. Вклад одной установки ограничен:
не больше 100 000 онлайн и 10 000 000 заказов. С одного адреса принимается не больше 20 новых `id` в час.
Адрес отправителя нужен только для этого лимита, держится в памяти и не записывается.

Числа присылают сами установки, сеть их не проверяет. Поэтому это счётчик, а не статистика.

## Свой сервер сети

Сервер сети открытый: `joblox hub` из того же бинарника.

```bash
JOBLOX_HUB_ADDR=127.0.0.1:8099 JOBLOX_HUB_DB=data/hub.db ./bin/joblox hub
docker compose -f deploy/hub/docker-compose.yml up -d --build   # или в Docker
```

HTTPS даёт Caddy (пример в `deploy/hub/docker-compose.yml`). Журнал Caddy для сети лучше выключить, чтобы не
хранить адреса установок.

## Почему так устроено

Сеть хранит только анонимные числа и показывает только суммы. В ней нет витрин, товаров, денег и персональных
данных, поэтому через неё нельзя ничего продать или рекламировать, и модерировать в ней нечего.
Каждая установка остаётся отдельным бизнесом своего владельца, который сам отвечает за то, что и как продаёт.
