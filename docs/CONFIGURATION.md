# Настройки

Всё задаётся переменными окружения. `joblox up` дополнительно читает файл `joblox.env` в своей папке
(строки `КЛЮЧ=значение`), переменные окружения важнее файла. В боевом режиме (`JOBLOX_ENV=prod`, по умолчанию) сервер не запустится
без секрета, адреса сайта, почты и бота: он перечислит, чего не хватает.

| Переменная | По умолчанию | Что это |
|---|---|---|
| `JOBLOX_ENV` | `prod` | `dev` для своего компьютера: письма не отправляются, а видны на `/dev/outbox` |
| `JOBLOX_PROFILE` | | Путь к профилю бизнеса, обязательно |
| `JOBLOX_REQUISITES` | | Путь к файлу реквизитов. Пусто: оплата переводом выключена |
| `JOBLOX_DB` | `data/joblox.db` | Файл базы SQLite |
| `JOBLOX_ADDR` | `:8080` | Адрес витрины |
| `JOBLOX_ADMIN_ADDR` | `127.0.0.1:9180` | Адрес дашборда и `/metrics`. Не открывайте наружу |
| `JOBLOX_BASE_URL` | | Публичный адрес, `https://` в боевом режиме: из него собираются ссылки в письмах. Адрес с путём (`https://example.com/shop`) ставит сайт под этот путь: все ссылки, переходы и cookie остаются под `/shop`, прокси передаёт путь как есть |
| `JOBLOX_DEMO` | | `1`: сайт-пример. Работает без почты и бота, на каждой странице плашка «заказы никто не выполнит», реквизиты просят не платить, пустой магазин заполняется примерами товаров |
| `JOBLOX_SECRET` | | Не меньше 32 случайных символов: `openssl rand -hex 32`. Ключ для кодов, CSRF и хэшей адресов |
| `JOBLOX_OWNER_KEY` | | Не меньше 32 случайных символов: `openssl rand -hex 24`. Включает кабинет владельца на сервере: заказы, товары с фото, дашборд. Вход по ссылке `JOBLOX_BASE_URL/owner/enter?k=КЛЮЧ`, ссылку никому не пересылайте. `joblox up` создаёт ключ сам |
| `JOBLOX_TRUSTED_PROXIES` | `127.0.0.1,::1` | Прокси, чьему `X-Forwarded-For` верить (Caddy, nginx) |
| `SMTP_HOST`, `SMTP_PORT` | порт 587 | Почтовый сервер. Порт 465: TLS сразу, иначе STARTTLS обязателен |
| `SMTP_USER`, `SMTP_PASSWORD` | | Вход на почтовый сервер |
| `SMTP_FROM` | | Отправитель: `Пекарня <shop@example.com>` |
| `SMTP_INSECURE` | | `1` разрешает SMTP без шифрования, только для сервера на localhost |
| `TELEGRAM_TOKEN` | | Токен бота от @BotFather |
| `JOBLOX_OPERATORS` | | Telegram-id операторов через запятую. Бот отвечает только им |
| `JOBLOX_NETWORK_URL` | | Адрес Joblox Network. Пусто или `off`: установка ничего никуда не отправляет. `joblox up` ставит https://joblox.openline.one сам. См. [NETWORK.md](NETWORK.md) |
| `JOBLOX_CALL_URL` | | Звонок внутри заказа: клиент и исполнитель открывают одну ссылку и говорят без номеров, пока заказ открыт. `joblox up` ставит https://openline.one/ (Контакт) сам. Пусто или `off`: кнопки нет |
| `JOBLOX_HOME` | `joblox-data` рядом с программой | Только для `joblox up`: папка с профилем, базой, ключами и `joblox.env` |
| `CLOUDFLARE_TUNNEL_TOKEN` | | Только для `joblox up`: токен своего туннеля Cloudflare. Вместе с `JOBLOX_BASE_URL` даёт постоянный адрес на своём домене вместо временного |
| `JOBLOX_NO_BROWSER` | | Только для `joblox up`: не открывать браузер, только напечатать мастер-ссылку |
| `JOBLOX_HUB_ADDR` | `127.0.0.1:8099` | Только для `joblox hub`: адрес сервера сети |
| `JOBLOX_HUB_DB` | `data/hub.db` | Только для `joblox hub`: база сервера сети |
| `JOBLOX_HUB_ADMIN_TOKEN` | | Только для `joblox hub`: токен модерации, `POST /api/v1/hide`. Пусто: модерация выключена |
| `JOBLOX_HUB_CONTACT` | | Только для `joblox hub`: куда жаловаться на карточку, выводится внизу страниц |

## Как узнать свой Telegram-id

Запустите сервер с токеном и любым id в `JOBLOX_OPERATORS`, напишите боту. Если вы не оператор, бот ответит
вашим id: допишите его в переменную и перезапустите сервер.

## Почта

Подойдёт любой сервис с SMTP: почта для домена у вашего регистратора, Яндекс 360, Mail.ru для бизнеса, Brevo,
Mailgun. Чтобы письма не попадали в спам, добавьте для домена записи SPF, DKIM и DMARC по инструкции сервиса.
Многие VPS-хостинги закрывают порты 25, 465 и 587: тогда берите сервис с портом 2525.
