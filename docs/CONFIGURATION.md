# Настройки

Всё задаётся переменными окружения. В боевом режиме (`OPENLINE_ENV=prod`, по умолчанию) сервер не запустится
без секрета, адреса сайта, почты и бота: он перечислит, чего не хватает.

| Переменная | По умолчанию | Что это |
|---|---|---|
| `OPENLINE_ENV` | `prod` | `dev` для своего компьютера: письма не отправляются, а видны на `/dev/outbox` |
| `OPENLINE_PROFILE` | | Путь к профилю бизнеса, обязательно |
| `OPENLINE_REQUISITES` | | Путь к файлу реквизитов. Пусто: оплата переводом выключена |
| `OPENLINE_DB` | `data/openline.db` | Файл базы SQLite |
| `OPENLINE_ADDR` | `:8080` | Адрес витрины |
| `OPENLINE_ADMIN_ADDR` | `127.0.0.1:9180` | Адрес дашборда и `/metrics`. Не открывайте наружу |
| `OPENLINE_BASE_URL` | | Публичный адрес, `https://` в боевом режиме: из него собираются ссылки в письмах |
| `OPENLINE_SECRET` | | Не меньше 32 случайных символов: `openssl rand -hex 32`. Ключ для кодов, CSRF и хэшей адресов |
| `OPENLINE_TRUSTED_PROXIES` | `127.0.0.1,::1` | Прокси, чьему `X-Forwarded-For` верить (Caddy, nginx) |
| `SMTP_HOST`, `SMTP_PORT` | порт 587 | Почтовый сервер. Порт 465: TLS сразу, иначе STARTTLS обязателен |
| `SMTP_USER`, `SMTP_PASSWORD` | | Вход на почтовый сервер |
| `SMTP_FROM` | | Отправитель: `Пекарня <shop@example.com>` |
| `SMTP_INSECURE` | | `1` разрешает SMTP без шифрования, только для сервера на localhost |
| `TELEGRAM_TOKEN` | | Токен бота от @BotFather |
| `OPENLINE_OPERATORS` | | Telegram-id операторов через запятую. Бот отвечает только им |

## Как узнать свой Telegram-id

Запустите сервер с токеном и любым id в `OPENLINE_OPERATORS`, напишите боту. Если вы не оператор, бот ответит
вашим id: допишите его в переменную и перезапустите сервер.

## Почта

Подойдёт любой сервис с SMTP: почта для домена у вашего регистратора, Яндекс 360, Mail.ru для бизнеса, Brevo,
Mailgun. Чтобы письма не попадали в спам, добавьте для домена записи SPF, DKIM и DMARC по инструкции сервиса.
Многие VPS-хостинги закрывают порты 25, 465 и 587: тогда берите сервис с портом 2525.
