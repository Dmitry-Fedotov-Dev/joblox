# Бот операторов

Бот работает через Telegram Bot API и отвечает только аккаунтам из `OPENLINE_OPERATORS`. Остальным он сообщает
их id и ничего не делает.

## Карточка заказа

На каждый новый заказ бот присылает карточку: позиции, сумма, ответы клиента, способ оплаты, номер для
назначения платежа, подтверждён ли email, решение антифрода с причинами. Под карточкой кнопки:

| Кнопка | Когда видна | Что делает |
|---|---|---|
| ✅ Одобрить | Заказ на ручной проверке | Снимает проверку, клиент видит реквизиты |
| 💰 Оплата получена | Цена известна, оплаты ещё нет | Отмечает оплату. Сначала сверьте поступление в банке |
| → Переход | Переход профиля разрешён оператору сейчас | Меняет статус, клиенту уходит письмо, если в профиле `notify: true` |
| ⛔ В чёрный список | Заказ не закрыт | Блокирует почту и телефон клиента |

Если переход есть, но условие не выполнено, карточка пишет об этом: «Выдан ждёт оплаты». Если два оператора
нажали кнопки одновременно, выполнится одно нажатие, второму бот ответит «Заказ уже изменили» и обновит карточку.

## Команды

| Команда | Что делает |
|---|---|
| `/orders` | Последние 15 открытых заказов |
| `/review` | Заказы на ручной проверке |
| `/order 12` | Карточка заказа с кнопками |
| `/price 12 4500` | Назвать цену заказа (профили с ценой по запросу). Называя цену, вы одобряете заказ |
| `/paid 12 п/п 345` | Отметить оплату с комментарием |
| `/block anna@example.ru` | В чёрный список почту или телефон, `/unblock` убирает |
| `/stats` | Заказы, оплаты и выручка за сутки |
| `/pause причина` | Остановить приём новых заказов. `/resume` возобновляет |

## Сообщения без вашего действия

- Запуск сервера: название, версия и отпечаток реквизитов.
- Клиент подтвердил email или сам отменил заказ.
- Неоплаченный заказ закрыт по сроку.
- Антифрод отклонил попытки: сводка не чаще раза в 10 минут, чтобы атака не завалила чат.

Бот получает обновления опросом (long polling): ему не нужен входящий адрес. Запускайте один экземпляр сервера
с одним токеном, иначе Telegram отдаст обновления то одному, то другому.
